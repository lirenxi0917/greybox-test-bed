# greybox-test-bed

A greybox test bed for prototyping mechanics, level geometry, and interaction logic before art pass.

## Scope

- Greybox placeholder blocks / volumes representing intended play space and navigation.
- Core movement, collision, and trigger interactions built with primitive shapes.
- Tunable layout parameters that can be iterated quickly without art assets.
- Sandbox for validating fun, flow, and spacing decisions before detailed production.

## Stack (scaffold)

- Engine/runtime: TBD (to be pinned in the first implementation commit).
- Placeholder art: primitive meshes / flat-colored boxes.
- No final assets committed to this bed; they live in the production project.
