# Validation Checklist (pre art pass)

Run before any layout is handed to production.

## Flow
- [ ] Player can read the intended route at a glance.
- [ ] No dead ends that trap the player without a reset path.
- [ ] Cover / choke points are placed where the intended pacing calls for them.

## Spacing
- [ ] Doorways and corridors are wide enough for comfortable movement.
- [ ] Obstacles do not block sightlines unintentionally.
- [ ] Trigger zones sit where the player naturally passes.

## Pacing / Feel
- [ ] Movement speed feels responsive; values are tunable.
- [ ] Room-to-corridor transitions do not feel cramped or empty.
- [ ] Trigger feedback is noticeable without being distracting.

## Reproducibility
- [ ] Scene loads from the committed repository without manual setup.
- [ ] All key layout parameters are documented in the config/parameter table.
